```bash
npm install
npm run dev
```

## Deploy na Vercel (2 cliques)
1. Suba este repo no GitHub (já configurado).
2. Acesse https://vercel.com/new → Import Git Repository → selecione `reobote-eletrica-seguranca`.
3. Framework: Next.js (auto). Sem variáveis de ambiente.
4. Deploy → URL pronta para enviar ao cliente.
